# elinkBook (易閱書) — 匠心雕琢的九大核心閱讀體驗

來源：`site/index.html` 官方網站核心特色專區

## 產品定位
專為繁體中文直排與 E-Ink 電子墨水屏深度客製的極致電子書閱讀器。融匯東方古典書香美學與現代排版技術，重拾紙質墨香與直排閱讀樂趣。

## 九大核心特點

1. **繁體直排深度優化**
   遵循標準繁體中文排版規範，精準處理直排標點居中、破折號與引號直向旋轉、避頭尾法則，杜絕標點落於行首的排版瑕疵。支援直橫排即時切換。

2. **PDFium 原生極速渲染**
   透過底層 FFI 直接對接 PDFium 高效能引擎，超過 100MB 的大型圖文 PDF 與掃描書均可在 2 秒內極速加載，縮放滑順無卡頓。具備 Page-fit 模式、智慧裁切白邊、橫向雙頁模式。

3. **E-Ink 電子墨水屏適配**
   專為文石 (Boox)、墨案 (Moan)、讀墨 (Readmoo) 等 E-Ink 裝置設計，支援純黑白高對比渲染、無動畫瞬翻、實體音量鍵翻頁、零殘影刷新、無 GMS 相容。

4. **Calibre & OPDS 遠端書庫**
   無縫串接私人 Calibre 書庫與標準 OPDS 協議站點，支援目錄瀏覽、線上搜尋與一鍵下載匯入本機，打造無邊界的私人雲端圖書館，支援 Google Drive、OneDrive 同步。

5. **九宮格自由熱區導航**
   獨創 3×3 觸控熱區自訂系統，提供「左手持機」、「右手翻頁」、「單手操作」多種預設模式，更支援自訂每一格的點擊跳頁動作與防誤觸。

6. **Markdown 筆記匯出與語音朗讀**
   書籍劃線、思考筆記可一鍵匯出為標準 Markdown 格式，輕鬆銜接 Obsidian、Logseq 等知識管理工具；更支援原生 TTS 句級高亮朗讀與多色劃線註記。

7. **雙向簡繁智慧轉換**
   精準雙向簡繁即時轉換，整合 OpenCC 詞庫與台灣常用語在地化字典（如「軟體」、「記憶體」）。採無損顯示層渲染與分段偏移映射，不修改原始檔案，劃線、註記與 CFI 閱讀座標 100% 精準無偏差，並連動全文檢索與 TTS 朗讀。

8. **同區網 WiFi 隔空傳書**
   在同一 Wi-Fi 區域網路或手機自開熱點下，電腦、平板透過瀏覽器輸入專屬網址即可連線。支援拖曳批次上傳、即時進度通知，亦可直接瀏覽與下載已存圖書至電腦，免裝任何 App、純區網傳輸零外洩。

9. **自建伺服器雲端同步**
   自行架設 PocketBase 同步伺服器，同步閱讀進度、書籤、劃線與備註。資料只存在你的伺服器，資料自主、純本機優先。
