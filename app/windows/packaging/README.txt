elinkBook Windows 使用說明（免安裝版與安裝版）
==============================================

感謝使用 elinkBook 電子書閱讀器 Windows 版（免安裝 zip 與安裝程式皆適用，安裝程式見第七節）。

一、系統需求
------------
1. 作業系統：Windows 10（1809 以上版本，64 位元 x64架構）或 Windows 11。
   （註：Windows 10 1809 之相容性實測標註為「未驗證」，以本機 Windows 11 驗證為主）
2. 執行環境：Microsoft Edge WebView2 Runtime。
   - 本程式需要此元件才能顯示書籍內容。
   - 若系統尚未安裝，啟動 App 時會顯示說明畫面，並提供微軟官方下載連結。
3. VC++ 執行階段：本套件已隨附所需之 Visual C++ 執行階段 DLL（app-local 部署），無需手動安裝。

二、使用方式
------------
1. 將下載的 zip 壓縮檔解壓至任何資料夾（支援含有空格或中文之路徑）。
2. 進入解壓後的資料夾，雙擊執行「elinkbook.exe」即可啟動。
3. 本程式為免安裝版，無需系統管理員權限。

三、資料存放位置與完整移除
--------------------------
應用程式的資料分放在兩個資料夾：
1. 設定與瀏覽資料：%APPDATA%\cc.ugotit\elinkbook
   - downloaded-fonts：已下載的字型
   - dictionaries：字典來源（有匯入字典才會有）
   - webview_data：WebView2 閱讀引擎資料
2. 書庫與匯入的書：使用者的「文件」資料夾下的 elinkbook-data 目錄（例如 C:\Users\<使用者>\Documents\elinkbook-data）
   - 包含書庫資料庫（library.db）、字典資料庫（dictionary.db）、封面、匯入的書的複本，以及雲端匯入、遠端下載、WiFi 傳書與更新暫存等資料。
   - 匯入時留在原位置的書檔不在這裡。
   - 注意：免安裝版解壓出來的程式資料夾叫 elinkbook，與這個資料資料夾 elinkbook-data 是不同的資料夾，兩者不要混為一談。
   - 若曾使用過舊版（收進 elinkbook-data 目錄之前），舊版留在「文件」根目錄的資料（如 library.db、covers、imported_books 等）不會被讀取、修改或自動刪除，可視需要自行手動刪除。

【移除方式】
- 直接刪除解壓後的程式資料夾即可移除應用程式。刪除程式資料夾不會刪除上述兩個資料夾。
- 若欲完全清除，請另外手動刪除上述兩個資料夾（%APPDATA%\cc.ugotit\elinkbook 與「文件」資料夾內的 elinkbook-data 目錄），請勿誤刪整個「文件」資料夾。
- 使用安裝版時，解除安裝可以選擇一併刪除這兩個資料夾（見第七節）。

四、未簽章提示與 SmartScreen 解除
---------------------------------
本版本未包含微軟商業程式碼數位簽章（Code Signing）：
1. 啟動時 Windows Defender SmartScreen 可能跳出「Windows 已保護您的電腦」警示視窗。
   請點擊「其他資訊」→ 點擊「仍要執行」即可啟動。
2. 若自網路下載本 zip 檔，Windows 可能自動附加網路安全標籤。解壓前建議：
   對 zip 檔案按右鍵 → 選擇「內容」→ 勾選視窗右下角的「解除封鎖」→ 點擊「確定」，再進行解壓縮。

五、已知限制（平台功能對等說明）
--------------------------------
依據架構設計（epic-66 決策 1），部分行動平台專屬功能在 Windows 版不提供：
- 雲端硬碟匯入（Google Drive／OneDrive OAuth 登入）
- 硬體音量鍵翻頁
- E-Ink 電子墨水專用殘影對比強化濾鏡
- 螢幕方向鎖定（直向／橫向感應旋轉）

六、檔案完整性查驗（SHA256）
----------------------------
在 PowerShell 中執行以下指令即可查驗下載檔案之 SHA256 雜湊：
  Get-FileHash -Algorithm SHA256 elinkbook-*-windows-x64.zip

比對輸出結果是否與發佈同名之「.sha256」文字檔案內容一致。

七、安裝版（setup.exe）
-----------------------
除了免安裝 zip，也提供安裝程式「elinkbook-<版本>-windows-x64-setup.exe」：
1. 安裝位置：預設為目前使用者的 %LOCALAPPDATA%\Programs\elinkBook，不需要系統管理員權限（不會跳出 UAC）。
2. 捷徑：一定會建立開始功能表項目；桌面捷徑為安裝時的可選項目，預設勾選。
3. 升級：直接執行新版安裝程式即可覆蓋舊版；若 elinkBook 正在執行，安裝程式會提示關閉。
4. 解除安裝：從「設定 → 應用程式」解除安裝。請先關閉 elinkBook，開著時解除安裝程式會拒絕執行。
   解除安裝完成時會詢問「是否同時刪除 elinkBook 的所有資料（包含書庫）」，預設為「否」（保留所有資料）；
   選「是」會刪除第三節列出的兩個資料夾（%APPDATA%\cc.ugotit\elinkbook 與「文件」資料夾內的 elinkbook-data 目錄），**刪除後無法復原**。
   不會動「文件」資料夾內的其他檔案，也不會刪除匯入時留在原位置的書檔。
   以靜默模式（/SILENT、/VERYSILENT）解除安裝時一律不詢問、不刪除任何資料。
5. 安裝版同樣未簽章，SmartScreen 提示與解除封鎖方法見上方第四節。
6. 免安裝版與安裝版共用同一份資料（第三節的兩處），請不要同時開啟兩份。
   原本使用免安裝版的人不需要先刪除，直接安裝即可沿用原有的書庫與閱讀紀錄。
