elinkBook Windows 免安裝版使用說明
====================================

感謝使用 elinkBook 電子書閱讀器 Windows 免安裝版。

一、系統需求
------------
1. 作業系統：Windows 10（1809 以上版本，64 位元 x64架構）或 Windows 11。
   （註：Windows 10 1809 之相容性實測標註為「未驗證」，以本機 Windows 11 驗證為主）
2. 執行環境：Microsoft Edge WebView2 Runtime。
   - 本程式需要此元件才能顯示書籍內容。
   - 若系統尚未安裝，啟動 App 時會顯示說明畫面，並提供微軟官方下載連結。
3. VC++ 執行階段：本套件已隨附所需之 Visual C++ 執行階段 DLL（app-local 部署），無需手動安裝。

二、使用方式
------------
1. 將下載的 zip 壓縮檔解壓至任何資料夾（支援含有空格或中文之路徑）。
2. 進入解壓後的資料夾，雙擊執行「elinkbook.exe」即可啟動。
3. 本程式為免安裝版，無需系統管理員權限。

三、資料存放位置與完整移除
--------------------------
為支援唯讀目錄執行與遵守 Windows 應用規範，應用程式資料存放在使用者設定目錄：
- 書籍資料庫與偏好設定：%APPDATA%\cc.ugotit\elinkbook
- WebView2 閱讀引擎資料：%APPDATA%\cc.ugotit\elinkbook\webview_data

【移除方式】
- 直接刪除解壓後的程式資料夾即可移除應用程式。刪除程式資料夾不會刪除您的書籍與閱讀紀錄。
- 若欲完全移除所有閱讀進度與資料庫，請手動刪除上述「%APPDATA%\cc.ugotit\elinkbook」資料夾。

四、未簽章提示與 SmartScreen 解除
---------------------------------
本版本為開源／自用免安裝發佈，未包含微軟商業程式碼數位簽章（Code Signing）：
1. 啟動時 Windows Defender SmartScreen 可能跳出「Windows 已保護您的電腦」警示視窗。
   請點擊「其他資訊」→ 點擊「仍要執行」即可啟動。
2. 若自網路下載本 zip 檔，Windows 可能自動附加網路安全標籤。解壓前建議：
   對 zip 檔案按右鍵 → 選擇「內容」→ 勾選視窗右下角的「解除封鎖」→ 點擊「確定」，再進行解壓縮。

五、已知限制（平台功能對等說明）
--------------------------------
依據架構設計（epic-66 決策 1），部分行動平台專屬功能在 Windows 版不提供：
- 雲端硬碟匯入（Google Drive／OneDrive OAuth 登入）
- 硬體音量鍵翻頁
- E-Ink 電子墨水專用殘影對比強化濾鏡
- 螢幕方向鎖定（直向／橫向感應旋轉）

六、檔案完整性查驗（SHA256）
----------------------------
在 PowerShell 中執行以下指令即可查驗下載檔案之 SHA256 雜湊：
  Get-FileHash -Algorithm SHA256 elinkbook-*-windows-x64.zip

比對輸出結果是否與發佈同名之「.sha256」文字檔案內容一致。
