# ADR 0035：內建字型不隨 APK 散布，改由 Cloudflare R2＋Worker 提供下載

## 狀態

已採納（2026-09-25，`epic-49-downloadable-fonts`）

## 背景

PRD FR-09 原本要求「預置」5 款內建字型（思源黑體、思源宋體、原俠正楷、台灣圓體、源流明體），字型檔合計約 140MB，其中思源宋體可變字型就有 57MB。開發期為了加快建置，只打包了原俠正楷；`epic-48` 診斷時發現，選思源兩款「看起來正常」，其實是 `@font-face` 載入失敗後 WebView 退回系統的 Noto Sans CJK（和思源黑體是同一套字型設計），選思源宋體時很可能顯示成黑體。

要讓內建字型真正可用，只有兩條路：全部打包（APK 增加約 140MB），或讓使用者需要時再下載。

## 決策

1. **5 款內建字型一律不打包進 APK**，改為「可下載字型」：使用者在字型管理畫面主動下載，下載後存在 App 私有目錄、完全離線使用。
2. **字型檔放在 Cloudflare R2，透過 Cloudflare Worker 對外提供**，網址使用 Worker 的 `workers.dev` 子網域。
3. **發布路徑帶版本號**（`v1/<檔名>`），已發布的檔案**永遠不覆蓋、不刪除**；App 寫死每個檔案的網址與 SHA-256，下載後必須驗證雜湊。
4. **閱讀器以原生 `InternalStoragePathHandler` 串流服務下載的字型**（`/downloaded-fonts/`），不經過 Dart 攔截讀取位元組。
5. **刪除已下載的字型不清除書籍的字型偏好**，重新下載後自動恢復。

## 後果

- APK 不含任何字型檔。剛安裝的 App 在使用者下載前，只有書本字型與系統字型可用；PRD FR-09 已改寫為可下載字型。
- 產品多了一項外部依賴：下載服務停擺時，已下載的字型不受影響，但新使用者無法下載。免費額度（R2 儲存 10GB、每月 1,000 萬次讀取、不收下載流量費；Worker 每天 10 萬次請求）遠高於預期用量，但啟用 R2 必須綁定付款方式。
- 已發布版本的 App 永遠依賴 `workers.dev` 網址與 `v1/` 路徑，這兩者都不能拿掉。之後若把 ugotit.cc 的 DNS 搬到 Cloudflare 並改用 `fonts.ugotit.cc`，新舊網址必須並存。
- 字型改版需要發新版 App（新的版本路徑與雜湊）；舊版本檔案的本機清理留待改版時處理。
- 「已下載」的判斷只看正式檔案是否存在：下載時先寫暫存檔，驗證雜湊後才改名，所以正式檔案存在就代表完整，不需要另外用資料表記錄狀態，也不會有資料表和檔案不同步的問題。
- **和 ADR 0021（自訂字型不複製）的差異**：自訂字型是使用者自己的檔案，複製一份會讓儲存空間加倍，所以直接引用 `content://`；可下載字型沒有原始檔可以引用，下載下來的就是唯一的一份，只能由 App 保管。
- **和 ADR 0021 在服務方式上的差異**：ADR 0021 採用「Dart 攔截＋一次性讀取位元組」，前提是字型檔只有數十 KB 到數 MB。可下載字型最大 57MB，若沿用這個做法，每次請求都要把整個檔案讀進 Dart 記憶體，再經過 platform channel 複製給 WebView。檔案已經在 App 私有目錄裡，正好比照書本檔案（ADR 0021 當時排除的 `InternalStoragePathHandler`，排除理由是自訂字型不在私有目錄）交給原生端直接串流。原本讀取 Flutter asset 的攔截分支隨之移除。
- **和自訂字型的刪除行為不同**：刪除自訂字型會把使用中的書籍偏好清成 `null`（`deleteAndResetUsage`），刪除可下載字型則保留偏好。可下載字型的身分（家族名稱）固定不變、隨時可以重新下載；自訂字型刪除後就不會再出現同一筆，保留偏好沒有意義。

## 曾考慮的替代方案

- **全部打包進 APK**：保證所有裝置一安裝就能用，但 APK 增加約 140MB（只打包思源兩款也要約 96MB）。使用者選擇以安裝檔大小為優先，予以排除。
- **Cloudflare Pages（靜態網站）**：免費、不用綁付款方式，還附免費子網域。但單一檔案上限 25 MiB，思源黑體（34.4 MiB）、思源宋體（57.1 MiB）都放不下；轉成 WOFF2 後思源宋體仍可能超過上限，還要拆檔或做子集化。曾考慮「思源兩款打包、另外 3 款放 Pages」的混合方案，使用者仍選擇全部可下載，予以排除。
- **R2 綁定自訂網域 `fonts.ugotit.cc`**：網址最漂亮，但 R2 自訂網域要求整個網域的 DNS 由 Cloudflare 代管。ugotit.cc 目前 DNS 在 GoDaddy，而且有 Zoho 郵件的 MX／SPF 記錄，搬遷漏掉任何一筆就會收不到郵件。為了不動郵件 DNS，改用 Worker 的 `workers.dev` 網址，予以排除（保留為未來選項）。
- **R2 內建的 `r2.dev` 網址**：Cloudflare 標示有流量限制、不適合正式環境使用，予以排除。
- **直接連原作者的 GitHub Releases**：不用維護主機，但原作者的 release 大多是多字重的 zip 壓縮檔（源流明體全字重達數百 MB），網址也不受我們控制，予以排除。
- **遠端字型清單檔（manifest）**：可以不發新版就新增字型，但目前只有 5 個固定檔案，寫死網址和雜湊最簡單、也最容易驗證，留待真正需要時再擴充。
- **覆蓋式更新字型檔**：網址不用改，但已安裝的舊版 App 下載後雜湊驗證會失敗，予以排除。
