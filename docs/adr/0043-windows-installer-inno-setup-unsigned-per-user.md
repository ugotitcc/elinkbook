# ADR 0043：Windows 發佈形式採 Inno Setup 安裝程式（不簽章、依使用者安裝、固定 AppId），並保留 zip 免安裝版

## 狀態

已採納（2026-11-13）。對應 `epic-66-windows-port` Issue 27。承接 Issue 14（免安裝 zip）與 epic-66 決策 10（「先自用」）；Windows 版改為對外發佈後，決策 10 的「先自用」不再適用。

## 背景

Windows 版原本只有免安裝 zip（Issue 14）。對外發佈需要一般使用者習慣的安裝程式：有開始功能表項目、可從「設定 → 應用程式」解除安裝、可直接覆蓋升級。作者沒有程式碼簽章憑證，也沒有乾淨機器可驗證。App 資料本來就放在 `%APPDATA%\cc.ugotit\elinkbook`，與程式資料夾分開。

## 決策

1. **安裝程式用 Inno Setup**，輸出單一 `elinkbook-<版本>-windows-x64-setup.exe`；zip 免安裝版保留，兩者並列於 Release。
2. **不簽章**。安裝程式與 zip 一樣會跳 SmartScreen「仍要執行」，沿用 `app/windows/packaging/README.txt` 的說明。有使用者回報被擋時，再另開 Issue 評估憑證。
3. **依目前使用者安裝**：預設 `%LOCALAPPDATA%\Programs\elinkBook`，不需系統管理員權限。
4. **固定 `AppId`（GUID）**：新版直接覆蓋安裝舊版，App 執行中時提示關閉。**這個 GUID 一經發佈就不可更改**——改了之後，Windows 會把新舊版視為兩個不同的 App，舊版使用者無法覆蓋升級，只會並存兩份。
5. **解除安裝預設保留使用者資料**，但跳出詢問「是否同時刪除書庫與閱讀紀錄」（`%APPDATA%\cc.ugotit\elinkbook`），預設「否」；靜默解除安裝（`/SILENT`、`/VERYSILENT`）一律不刪。

## 替代方案與取捨

- **MSIX**：被否決。沒有受信任的憑證簽章就無法雙擊安裝，等於一定要先取得憑證；Windows 10 1809 與 MSIX 的相容條件也增加變數。
- **只維持 zip**：被否決。沒有「設定 → 應用程式」的移除入口，也沒有開始功能表與一般使用者預期的升級方式。
- **依機器安裝（`Program Files`）**：被否決。需要系統管理員權限，且與 zip 版「不需要管理員」的體驗不一致。
- **解除安裝一律刪除或一律保留、不詢問**：被否決。一律刪除會誤刪使用者的書庫；一律保留則使用者沒有直接清乾淨的途徑。

## 後果

- 未簽章意味著 SmartScreen 警示不會因為安裝程式而消失，這是已知且接受的代價。
- zip 版與安裝版可並存，兩者共用同一份資料，**不可同時開兩份**，說明文件須提醒。
- 乾淨機器、Windows 10 1809 與 SmartScreen 實際行為仍未驗證（作者沒有另一台電腦或虛擬機）。
