# ADR 0009：3×3 熱區映射模式改為使用者手動選擇，不隨橫直排自動鏡像

## 狀態

已採納（`epic-7-interaction` Discovery，`docs/epics/epic-7-interaction/design.md`）。

## 背景

PRD FR-24 原文要求「直排 (RTL) 模式下，熱區映射須自動左右鏡像翻轉以符合右翻書邏輯」——即熱區的上一頁/下一頁映射應隨書籍目前的排版方向（橫排 LTR／直排 RTL）自動翻轉，不需使用者介入。

但 FR-24 同時也要求「單手模式」讓左右熱區可各自獨立設定翻頁方向，目的是「適應左右手持機習慣」。Discovery 過程中發現這兩個訴求會互相打架：若熱區映射隨排版方向自動鏡像，使用者為了持機習慣手動選定的模式，會在切換書籍排版方向時被系統靜默覆寫，兩種「使用者意圖」（持機習慣 vs. 排版方向）無法同時滿足。

## 決策

3×3 熱區的映射模式（左翻頁／右翻頁／單手／自訂）一律由使用者手動選擇，**不**依書籍橫排/直排狀態自動鏡像翻轉。使用者若在直排書籍下想要「右翻」邏輯的熱區映射，自行切換到對應模式即可；系統不做任何隱性覆寫。

## 後果

- 與 PRD FR-24 原文字面要求（自動鏡像）不符，已同步修正 `docs/prd.md` FR-24 文字與 editHistory。
- 熱區設定為全域生效（不分書籍），使用者只需設定一次，不會因為換書、換排版方向而需要重新確認熱區行為，行為更可預測。
- 犧牲了「開一本直排書自動變成慣用右翻邏輯」的零設定體感；換取「持機習慣穩定不受書籍內容影響」的一致性。

## 曾考慮的替代方案

- **自動鏡像為主、手動選擇為輔**：以排版方向決定基準映射，使用者手動選擇的模式再疊加一層鏡像轉換。邏輯複雜（兩層轉換疊加後的最終結果不直覺），且使用者手動選了模式卻在切換書籍時看到熱區行為改變，體感上像是「設定沒生效」，予以排除。
