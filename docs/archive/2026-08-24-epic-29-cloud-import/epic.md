`CONTEXT.md`），僅完全比對相同才提示，刻意不做書名/作者模糊比對（已知落差：PDF/TXT/CBZ 跨來源重複本波抓不到）。`BookSource`（`local`/`googleDrive`/`oneDrive`）與雲端檔案 ID 保留為書籍的永久來源標記，供 Round 4/5 決策使用。`CONTEXT.md` 新增/更新 3
