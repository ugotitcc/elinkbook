完工並歸檔，排序限制解除）。**2026-08-03 完成 Architecting**（`spec.md`，`/grill-with-docs`）：`/grilling` 過程中發現 design.md 未涵蓋的架構缺口——`bookmarks`/`highlights`/`notes` 三表用本機自增整數 id、`notes.highlight_id` 也參照本機整數 決策 3 措辭）；`books.id` 格式維持不變（跨裝置比對用途已由 `content_fingerprint` 承擔，改 UUID 零效益）。定案 4 個 PocketBase collection（`sync_reading_positions`／`sync_bookmarks`／`sync_highlights`／`sync_notes`，皆以 `user` relation 隔離，`book_fingerprint` 存純文字非 relation）；checkpoint 批次上傳採 PocketBase Batch API（需伺服器 ≥ 0.23）、下載走一般查詢；書籍內容指紋演算法定案 SHA-256、PDF/TXT 全檔案雜湊不抽樣（正確性優先於一次性匯入成本）；5 分鐘閒置計時器維持；PocketBase 自架 SOP 文件範圍界定 4 個部分（最低版本／collection 建立步驟／最簡 Docker 啟動／備份建議）；依賴套件定案官方 `pocketbase` Dart package。SQLite migration 定案 v16→v17。**2026-08-03 完成 spec.md
