# `epic-56-pdf-paginated-reading` 規格（SPEC）

> 本檔案是此 Epic 核心介面、型別與行為規則的唯一事實來源。產品決策與理由、查證過程、風險見同目錄 `epic.md`；各 Issue 的實作步驟見 `plans/`。詞彙遵循 `CONTEXT.md`（翻頁模式、逐頁、連續捲動、Fit 模式、spread、雙頁模式、裁切模式、位置儲存規則、閱讀會話）。

## Problem Statement

使用者在閱讀 PDF 時，一個畫面裡看不到「完整的一頁」：上一頁與下一頁都和目前這一頁連在一起，從畫面的上緣或下緣露出來。換頁時畫面是整份文件往上滑動一段距離後才停在下一頁，感覺不是「一頁換成另一頁」。這對想要一次看完一整頁、再翻到下一頁的閱讀習慣很不方便，在 E-Ink 螢幕上滑動動畫還會造成殘影。

另外，設定面板裡的「Fit 模式」（Page-fit／Fit Width／真實比例）目前只會存檔、不會影響畫面，使用者以為已經設定了整頁顯示，實際上沒有。

## Solution

PDF 新增「翻頁模式」，二選一：

- **逐頁**（新，預設）：畫面一次只顯示一頁（開啟雙頁模式時為一個 spread），鄰頁完全看不到；換頁是瞬間切換，沒有滑動動畫。Page-fit 下整頁一次看完。
- **連續捲動**（現況）：頁面上下相連，可自由捲動。

同時讓 Fit 模式真正生效：Page-fit 讓整頁（或整個 spread、或裁切後的頁面）完整放進螢幕；Fit Width 讓頁寬滿版、頁面比螢幕高時可上下閱讀；真實比例不縮放。

逐頁模式下，頁面比螢幕高時，點「下一頁」熱區或按音量鍵會先往下捲一個螢幕（保留少量重疊），捲到頁底才換到下一頁；未放大時左右滑動直接換頁。目錄、書籤、頁碼跳轉、搜尋結果都是瞬間抵達目標頁。

## User Stories

1. 身為 PDF 讀者，我希望一次看到完整的一頁且看不到上下鄰頁，以便專心閱讀目前這一頁而不被相連的頁面干擾。
2. 身為 PDF 讀者，我希望換頁是整頁瞬間切換而不是整份文件往上滑，以便閱讀節奏像翻書一頁一頁來。
3. 身為 E-Ink 裝置的使用者，我希望換頁沒有任何滑動過渡，以便減少殘影與刷新次數。
4. 身為 PDF 讀者，我希望預設就是逐頁，以便不用先去設定就得到整頁閱讀。
5. 身為已經在讀 PDF 的使用者，我希望升級後閱讀位置完全不變，以便從上次的頁碼接著讀。
6. 身為偏好連續捲動的使用者（例如長圖、掃描講義），我希望能在 PDF 設定面板切回連續捲動，以便保留原本的閱讀方式。
7. 身為使用者，我希望翻頁模式是每本書各自記住的，以便漫畫風 PDF 與論文各用各的方式。
8. 身為使用者，我希望切換翻頁模式後立即生效、停在原本那一頁，以便不用重新開書。
9. 身為使用者，我希望選了逐頁後，「PDF 翻頁動畫」選項自動隱藏，以便設定面板不出現無作用的選項。
10. 身為使用者，我希望選了連續捲動後，「PDF 翻頁動畫」選項再次出現並保留我原本的選擇，以便切回去時不用重設。
11. 身為使用者，我希望 Page-fit 真的把整頁（含上下左右）完整放進螢幕，以便不用縮放就能看全頁。
12. 身為使用者，我希望 Fit Width 讓頁寬剛好滿版，以便文字盡量大、直向閱讀長頁。
13. 身為使用者，我希望真實比例不縮放頁面，以便檢視實際尺寸。
14. 身為使用者，我希望 Fit 模式在連續捲動與逐頁兩種翻頁模式下都有作用，以便設定不會因模式不同而失效。
15. 身為讀者，我希望在 Fit Width 下頁面比螢幕高時，點「下一頁」熱區會先往下捲一個螢幕，以便單手連續讀完一頁。
16. 身為讀者，我希望往下捲時與上一個畫面保留少量重疊，以便不會因為剛好切在一行文字中間而漏讀。
17. 身為讀者，我希望捲到頁底之後再點「下一頁」才換頁，並出現在新頁的頂端，以便從頭開始讀新的一頁。
18. 身為讀者，我希望點「上一頁」時，頁內還沒回到頂端就先往上捲，回到頂端後才換到上一頁，以便與往下的行為對稱。
19. 身為讀者，我希望換到上一頁時畫面落在該頁頂端（而不是底端），以便位置可預期。
20. 身為使用者，我希望音量鍵與熱區的行為完全一致，以便單手操作不需要重新學習。
21. 身為使用者，我希望 Page-fit 下點「下一頁」就是直接換頁，以便不會出現多餘的頁內步進。
22. 身為使用者，我希望未放大時左右滑動就換頁，方向依雙頁方向設定鏡像，以便直排與由右至左的書符合習慣。
23. 身為使用者，我希望放大後橫向有溢出時，滑動是平移頁面而不是換頁，以便放大閱讀細節時不會誤翻頁。
24. 身為使用者，我希望在頁內垂直拖曳可以自由捲動較高的頁面，以便不依賴熱區也能閱讀。
25. 身為使用者，我希望長按拖曳框選劃線或備註時不會誤觸發換頁，以便標註時畫面保持穩定。
26. 身為使用者，我希望從目錄、書籤或輸入頁碼跳頁時瞬間抵達目標頁的頂端，以便不被上一頁的捲動位置影響。
27. 身為使用者，我希望從搜尋結果跳轉時，即使匹配處在較高頁面的下半部，畫面也自動帶到看得到高亮的位置，以便 3 秒的暫態高亮不會落在螢幕外。
28. 身為使用者，我希望開啟雙頁模式時，逐頁翻的單位是一個 spread，Page-fit 把整個 spread 放進螢幕，以便雙頁並排也是整組一次看完。
29. 身為使用者，我希望使用裁切模式時，逐頁與 Fit 模式以裁切後的頁面為準，以便去掉白邊後的內容盡量大。
30. 身為使用者，我希望在較高頁面上只用拖曳閱讀、頁碼沒變的期間，閱讀時間仍持續計算，以便閱讀統計不會因為沒翻頁就停止。
31. 身為使用者，我希望頁面頂端、頁碼與進度顯示在逐頁下仍是「目前顯示的那一頁」，以便進度與書籤位置一致。
32. 身為使用者，我希望頁內捲動到哪不影響進度儲存，離開重開回到該頁頂端，以便行為簡單可預期。
33. 身為使用者，我希望旋轉螢幕或改變視窗大小後仍停在同一頁，並依新尺寸重新套用 Fit 模式，以便旋轉不會跳頁。
34. 身為使用者，我希望縮放後換頁時，新的一頁回到該模式的預設縮放，以便每一頁起點一致。
35. 身為使用者，我希望朗讀（TTS）換頁時，逐頁畫面跟著瞬間切到朗讀所在頁，以便畫面與朗讀同步。
36. 身為使用者，我希望縮圖面板、全文搜尋面板、目錄等既有功能在逐頁下行為不變，以便不需要重新學習。
37. 身為使用者，我希望影像濾鏡（對比、亮度、加粗）在逐頁下照常生效，以便 E-Ink 閱讀品質不變。
38. 身為維護者，我希望新增的偏好欄位在所有重建偏好的地方都被保留，以便存設定時不會靜默清掉翻頁模式。
39. 身為維護者，我希望資料庫從舊版本升級後原有偏好完整保留，以便升級不影響既有使用者。
40. 身為維護者，我希望逐頁的核心規則是不依賴畫面的純邏輯並有具體數字的單元測試，以便之後調整門檻能放心。

## Implementation Decisions

### 型別與偏好

- 新增 PDF 專用的翻頁模式列舉，兩個值：`paginated`（逐頁）、`scroll`（連續捲動）。EPUB 既有的翻頁模式（分頁／捲動）不受影響，兩者是不同的型別、共用「翻頁模式」一詞。
- 單書偏好 `BookReaderPrefs` 新增可為空的 PDF 翻頁模式欄位；`null` 一律解讀為逐頁，與 Fit 模式「null＝Page-fit」同一套規則。無全域預設層。
- 最終生效偏好 `ResolvedPreferences` 新增非空的 PDF 翻頁模式，解析規則為「單書值，否則逐頁」。
- 資料庫：`book_reader_prefs` 新增 `pdf_page_turn_mode TEXT`（可為空，存列舉名稱，無法辨識的值視為 `null`）；schema 版本由 27 升到 28；升級時以 `ALTER TABLE ... ADD COLUMN` 追加，比照 `pdf_page_turn_animation` 的作法；初始建表 DDL 同步補上欄位。
- 所有以既有偏好重建 `BookReaderPrefs` 的地方（書架的版面覆寫、固定版面設定面板、PDF 設定面板）必須帶上新欄位，否則存其他設定時會把翻頁模式清掉。
- 序列化（`toMap`／`fromMap`／`copyWith`／相等與雜湊）全部涵蓋新欄位。

### 設定面板

- 翻頁模式放在 PDF 設定面板的「顯示」分頁，與 Fit 模式、PDF 翻頁動畫同一分頁，使用與其他二選一選項相同的 chip 元件。
- 選逐頁時隱藏「PDF 翻頁動畫」；選連續捲動時顯示，且保留先前的動畫選擇值（隱藏不清除）。
- 所有新字串經 `AppLocalizations`，四份 ARB（zh_TW、zh_CN、zh、en）同步新增，需通過硬編碼字串與 ARB 鍵一致性檢查。

### `PdfReaderView` 對外介面

- 新增 `pdfPageTurnMode` 建構參數。widget 層預設為連續捲動（保護既有的大量 `PdfReaderView` widget 測試）；產品預設的逐頁由 `ReaderScreen` 以解析後的偏好明確傳入，比照 `dualPageMode` 的作法。
- 既有 `pdfFitMode` 參數改為真正驅動縮放基準（連續捲動與逐頁皆然）。
- 既有靜態 helper（跳頁、上一頁、下一頁、刷新標註、暫態高亮）維持穩定簽章；逐頁下它們的語意見下方「導覽」。

### 逐頁導覽規則模組（純 Dart，不依賴 Widget）

導覽的單位稱為「**單元**」：未開啟雙頁模式時是一頁，開啟時是一個 spread（沿用既有 spread 規則：封面獨立、方向、錨點頁）。單元的幾何範圍是頁面矩形（有裁切時為裁切後矩形）或 spread 矩形。

模組提供下列行為（以輸入／輸出語意描述，具體命名在計畫階段決定）：

1. **縮放基準**：給定單元內容尺寸、可視尺寸與 Fit 模式，回傳基準縮放。
   - Page-fit：寬高兩個維度各自的比例取較小者。
   - Fit Width：可視寬度除以內容寬度。
   - 真實比例：固定為 1.0（不縮放）。
   - 縮放後內容比可視範圍小的維度置中；Fit Width 與真實比例縱向溢出時從頁頂開始；真實比例橫向溢出時從閱讀起始側開始（依雙頁方向：左到右靠左、右到左靠右）。
   - 使用者可在基準之上放大，不可縮到基準以下。
2. **頁內捲動範圍**：縱向最大捲動量＝（縮放後內容高度－可視高度），不為負；未溢出時為 0。
3. **相對步進（下一頁）**：若縱向可捲動且尚未到頁底，回傳「頁內往下捲」，新偏移＝目前偏移＋（可視高度－重疊量），上限為最大捲動量；若已到頁底（容許 1 個邏輯像素誤差）或沒有溢出，回傳「換到下一個單元，落在頂端、縮放回基準」；若已是最後一個單元，回傳「無動作」。
4. **相對步進（上一頁）**：對稱。若偏移大於 0，回傳「頁內往上捲」（新偏移＝目前偏移－步距，下限 0）；若已在頂端，回傳「換到上一個單元，**落在頂端**、縮放回基準」；已是第一個單元則「無動作」。
5. **重疊量**：可視高度的 10%（初始值，待真機校準後可調；為模組內單一具名常數）。
6. **絕對跳轉**：給定目標單元，回傳落在該單元頂端、基準縮放的視窗位置；不繼承任何先前的頁內偏移或縮放。目標頁屬於某個 spread 時，以該 spread 為單元。
7. **帶高亮的跳轉**（搜尋結果）：給定目標單元與高亮矩形（頁面座標）。若高亮在頂端對齊的視窗內完整可見，就維持頂端；否則把偏移設為讓高亮矩形垂直置中，並夾在 0 與最大捲動量之間；若高亮比可視高度還高，則讓高亮上緣貼齊可視上緣。
8. **滑動判定**：一次手勢被視為「滑動翻頁」需同時滿足：水平位移至少 56 邏輯像素、水平位移至少為垂直位移的 2 倍、手勢時長不超過 500 毫秒（以上為初始值，待真機校準，皆為具名常數）；且目前頁面沒有橫向溢出（Page-fit、Fit Width 恆沒有；真實比例以實際溢出判定）；且沒有長按拖曳框選進行中。判定成立時：依雙頁方向決定上一個或下一個單元（左到右：向左滑為下一個；右到左鏡像），落頂端、縮放回基準。不成立的手勢交由一般平移處理。
9. **閱讀活動判定**：頁內垂直拖曳的累積位移每達 20 邏輯像素回報一次閱讀活動，換手勢或換單元後歸零。
10. **當前頁**：逐頁下回報的頁碼是目前單元的錨點頁（單頁即該頁，雙頁為 spread 錨點頁），與頁內偏移無關。

### 幾何隔離（逐頁的 `layoutPages`）

- `pdfrx` 會繪製所有與可視矩形（含其快取外擴範圍）相交的頁面，因此逐頁模式不能只靠限制平移；必須讓版面座標上相鄰單元不可能同時落入任何可達的可視矩形。
- 不變式：在任何 Fit 模式、任何可達縮放（不小於基準）、任何合理螢幕比例、含 `pdfrx` 快取外擴下，可視矩形只與目前單元相交。
- 平移以 `normalizeMatrix` 鎖在目前單元的範圍內（含置中與溢出規則）；單元之間的間距足以滿足不變式。
- 雙頁 spread 與裁切版面使用同一套隔離規則：單元幾何取 spread 矩形或裁切後矩形。
- 具體間距公式（固定大值或依可視尺寸）由本 Epic 的第一個 spike 決定，spike 必須回答兩件事：（1）大座標下的浮點精度是否造成頁面抖動或對位誤差（數千頁時）；（2）視窗尺寸改變（旋轉、摺疊）時 `pdfrx` 是否會重算版面，若不會需由元件主動觸發。決定後把結論與公式補回本檔案。
- 連續捲動沿用既有 `layoutPages`（含雙頁與裁切），不受影響。

### 導覽入口對應

| 入口 | 逐頁下的語意 |
|---|---|
| 3×3 熱區的上一頁／下一頁、音量鍵 | 相對步進（規則 3、4） |
| 目錄、書籤、頁碼輸入、縮圖面板、全文搜尋面板（無高亮者） | 絕對跳轉（規則 6） |
| 搜尋結果跳轉（有高亮矩形） | 帶高亮的跳轉（規則 7） |
| 朗讀（TTS）依所在頁換頁 | 絕對跳轉（規則 6） |
| 左右滑動 | 滑動翻頁（規則 8） |
| 頁內垂直拖曳 | 自由平移（受範圍鎖定，規則 2），並依規則 9 回報閱讀活動 |

- 換頁一律瞬間完成，不套用任何動畫時長。連續捲動的翻頁動畫行為不變。
- 長按拖曳框選進行中暫時停用平移、縮放與滑動翻頁（沿用既有守衛）。
- 視窗尺寸改變（旋轉等）：維持同一單元，依新尺寸重算基準縮放，偏移回到頂端。
- 裁切編輯模式的行為不變（維持既有的導覽封鎖）。

### 閱讀會話與位置儲存

- 頁碼變化仍經 `ReadingSession` 的 PDF 頁碼回報；頁內垂直拖曳達門檻時呼叫 `ReadingSession` 既有的「回報一次閱讀活動」。
- 位置儲存規則不變：只存頁碼，進度＝（頁碼＋1）／總頁數；不新增儲存欄位、不改同步格式。逐頁下頁碼為單元錨點頁。

## Testing Decisions

- 好的測試只驗外部可觀察行為（決策結果、畫面上有哪些頁被繪製、存進資料庫的值），不驗內部狀態或私有呼叫順序。
- **接縫 1：逐頁導覽規則模組（純 Dart 單元測試，主要戰場）**。比照 `pdf_spread_layout.dart` 與其單元測試的做法，用具體數字當案例：
  - 縮放基準：不同頁面／可視尺寸比例下三種 Fit 模式的結果、置中與起點規則、橫向溢出的起始側。
  - 步進序列範例：頁高 2000、可視高 800、重疊 80 時，下一頁偏移依序為 0 → 720 → 1200（夾在最大捲動量）→ 換頁；上一頁從 1200 → 480 → 0 → 換到上一單元頂端。
  - 邊界：頁面不比螢幕高（直接換頁）、剛好等高、第一／最後單元、到頁底的 1 像素容許誤差。
  - 帶高亮的跳轉：高亮在頂端可見／不可見／比可視高度還高三種。
  - 滑動判定：剛好在門檻上下、斜向、太慢、有橫向溢出、框選進行中；左到右與右到左的方向鏡像。
  - 閱讀活動累積：達門檻回報、歸零。
  - 雙頁與裁切：單元幾何取 spread 矩形與裁切矩形。
- **接縫 2：`PdfReaderView` widget 測試（接線）**。比照既有 `pdf_reader_view_*_test.dart`，使用提交在版控的 `sample.pdf`：逐頁下鄰頁不被繪製（幾何隔離不變式的外部證據）、熱區與音量鍵觸發瞬間換頁、連續捲動行為不變（零回歸）、widget 層預設為連續捲動、框選進行中不換頁、頁碼回報為單元錨點頁。精確的數字規則不在此層重複測。
- **接縫 3：偏好持久化**。沿用既有偏好與 SQLite 倉儲測試位置：欄位序列化往返、`null` 與無法辨識值視為逐頁、v27→v28 升級保留既有偏好、所有重建偏好的地方不遺失新欄位；PDF 設定面板測試涵蓋選逐頁隱藏翻頁動畫、切回後顯示且保留原值。
- 既有大量 `PdfReaderView` widget 測試不得因本 Epic 而修改預設或失效（widget 層預設連續捲動正是為此）。
- **不以自動測試守住、列為待真機確認**：滑動翻頁手感與各門檻（56／2 倍／500 毫秒／20 像素／10% 重疊）、與長按框選及縮放平移的手勢衝突、E-Ink 上瞬間換頁的實際觀感。

## Out of Scope

- E-Ink 整頁黑白閃爍清屏（裝置相關，另立工單）。
- 頁內捲動位置的儲存與跨裝置同步。
- PDF 以外格式；EPUB 既有翻頁模式維持現狀。
- PDF Page Label、手寫／自由繪圖標註（既有限制）。
- 全域預設層的 PDF 翻頁模式。
- 更動雙頁模式、裁切模式、影像濾鏡本身的規則。
