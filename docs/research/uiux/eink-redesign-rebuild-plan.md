# elinkBook E-Ink 重構任務記錄

依據 `elinkBook-uiux-audit.dc.html` 第 5～8 節（建議設計系統／建議元件層級／建議畫面層級／改善優先順序）進行 UI 重構。這份文件記錄 grilling 討論定案的所有決策，做為階段 A／B／C 的施工依據。

## 三階段執行順序

1. **階段 A（先做，目前階段）**：另開新原型檔案，示範完整主題系統。
2. **階段 B（次做）**：把驗證過的畫面／元件決策，正式寫進 `DESIGN.md`。
3. **階段 C（最後）**：實際修改 Flutter 正式程式碼。屬於大型工程改動，要先在 `docs/epics.md` 開新 Epic／Issue，走 `CLAUDE.md` 規定的 SDD 流程，不能跳過規劃直接動手。

## 已定案的設計決策

### 色彩與主題
- **一次到位，不分批**：一次把 `ElinkTokens`（`DESIGN.md` 定義的 Light 晴空藍天／Dark 夜讀水墨／Sepia 宣紙古風 三主題 ＋ E-Ink 修飾子）設計進原型。
- **只用一個統一主題選擇器**：不拆 Chrome／Page 兩個獨立選擇器（雖然 `DESIGN.md` 原則允許兩者分開設，但這次原型為了好維護、不讓使用者混淆，選一次同時套用 Chrome 跟 Page）。
- **E-Ink 開啟時，主題選擇器要鎖住**：E-Ink 開啟後畫面固定純黑白，此時把主題選擇器改成鎖住／灰階狀態，不能再點；關閉 E-Ink 才能重新選主題。

### 導覽
- **不論主題，一律沿用「標題列右側圖示」**：不做底部導覽列版本。E-Ink 版跟一般主題版的導覽方式維持一致。

### 分類瀏覽
- **維持「下鑽」，不改篩選晶片**：稽核文件第 7 節「分類變成篩選」這項建議**不採納**，以 `DESIGN.md` 11.2 節「保留下鑽」為準——稽核文件這點被判定沒有修正到。階段 A／B／C 全部依此為準。

### 這次原型要新增的畫面／元件
- **書架加「繼續閱讀」列**：最上面固定一列「最近在讀的書」。
- **書架加「長按書籍→動作 Sheet」**：詳細資料／移動／版面覆寫／移除快取／刪除。
- **「來源」畫面加麵包屑導覽**：進 OPDS／雲端資料夾時用假資料示範一層下鑽＋麵包屑，不用真的接 OPDS 連線；下載佇列維持現有整合寫法。
- **「設定」畫面照稽核文件重新分區**：外觀（主題／E-Ink／字型）、閱讀（預設值／版面預設／導航熱區／朗讀語音與語速）、同步與帳號、關於（新增獨立區塊）。

### 原封不動保留的部分
- **既有 2b/2c 閱讀器、2d 版面設定四分頁**：邏輯與版面都不動，只需要能跟著新主題換色。

## 檔案安排
