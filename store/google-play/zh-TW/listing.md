貼到 Play Console「拓展 → 商店資訊 → 主要商店資訊」。字數上限由 Play 規定，改寫後要重新確認。

## 應用程式名稱（上限 30 字元）

```

```

## 簡短說明（上限 80 字元）

```
專為繁體中文直排與 E-Ink 打造的電子書閱讀器，標點置中、避頭尾排版正確，支援 EPUB、PDF、TXT
```

## 完整說明（上限 4000 字元）

```
elinkBook 易閱書是一款專為繁體中文閱讀設計的電子書閱讀器。直排標點置中、引號與破折號正確轉向、遵守避頭尾規則，讓電子書讀起來像紙本書一樣自然。

【繁體直排排版】
・直排與橫排一鍵切換
・標點置中，引號「」、破折號正確轉向
・遵守避頭尾規則，標點不會落在行首
・可自動偵測書本的排版方向

【支援格式】
・EPUB（流式與固定版面）
・PDF：大檔案也能快速開啟，支援裁切白邊、橫向雙頁、對比與亮度調整
・TXT：自動偵測編碼（UTF-8、Big5、GBK 等）與章節
・AZW3（KF8）、CBZ 漫畫、Markdown

【E-Ink 電子紙裝置友善】
・純黑白高對比模式，減少殘影
・實體音量鍵翻頁

【版面設定】
・字級、字重、行距、段落間距、字距，每一項都有滑桿與 +/- 微調
・上下左右邊界各自調整
・可停用書本內建的 CSS
・每本書可以有自己的設定，不影響其他書

【單手操作】
・3×3 九宮格觸控熱區，可自訂每一格的動作
・內建左手翻頁、右手翻頁、單手操作三種配置

【劃線、備註與書籤】
・多色劃線與螢光筆
・劃線與備註可一鍵匯出成 Markdown，方便放進 Obsidian 等筆記工具
・書籤可重新命名、刪除

【朗讀】
・使用手機內建的語音引擎朗讀，逐句高亮
・離開畫面後可在背景繼續播放

【簡繁轉換】
・雙向簡繁轉換，採用台灣常用詞彙
・只改顯示方式，不修改原始檔案，劃線位置不會跑掉

【取得書籍】
・從本機檔案或整個資料夾匯入
・從 Google Drive、OneDrive 匯入
・連線自架的 Calibre 書庫或 OPDS 書庫，瀏覽並下載
・Wi-Fi 傳書：同一個區域網路內，用電腦瀏覽器就能上傳、下載書籍，不經過外部伺服器

【閱讀同步（選用）】
・連線你自己架設的 PocketBase 伺服器，在多台裝置同步閱讀位置、書籤、劃線與備註
・開書時如果雲端位置跟本機不同，會先詢問你，不會直接跳走

【隱私】
・核心功能不需要註冊帳號，可以完全離線使用
・書籍檔案不會上傳
・隱私權政策：https://www.ugotit.cc/privacy

elinkBook 不提供書籍購買或租借，也不支援解除 DRM。請匯入你合法取得的電子書檔案。
```
